## The joke

> The office fridge thief kept stealing my lunch, so I relabeled it
> 'Q3 meeting notes' — nobody's opened it since.

(112 characters, well under the 200-character limit.)

## Run it

```sh
python3 main.py
# writes the entry line to /output/entry.txt (no trailing newline)
```
